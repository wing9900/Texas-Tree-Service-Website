# Instructions for Claude Code

Read AGENTS.md and then README.md in full before making any change to this repo. AGENTS.md holds the non-negotiable constraints; README.md is the complete operating manual.

Then read OPEN-ITEMS.md: the audited backlog of everything currently wrong, missing or temporary on the site, one entry per item with evidence, a reason it matters and a command to re-verify it. If you are asked what needs fixing, changing or editing on the website, answer from that file (re-verifying each item first, since it can go stale). Its Guardrails section lists things that look like bugs but are deliberate; read it before deleting anything.
